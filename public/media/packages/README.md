# WEEMAP Sinai package campaign heroes

These five images are WEEMAP-generated editorial package visuals created for
the 2026 package commercial pass. They represent the combined feeling of each
experience bundle; they are not documentary photographs of an exact trip
location and carry no photographer attribution.

Individual trip pages remain the source of real trip/location photography.

Each package has an original 1536×1024 PNG master and an 88-quality WebP web
derivative:

- `dahab-essentials`
- `the-dahab-mix`
- `wild-sinai`
- `into-the-blue`
- `sinai-after-dark`

Generated with OpenAI's native image-generation tool. No source photograph,
logo, rendered text, or third-party stock asset was used.
