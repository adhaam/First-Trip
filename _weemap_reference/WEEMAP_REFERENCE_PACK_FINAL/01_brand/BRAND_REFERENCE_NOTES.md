# WEEMAP SINAI — Brand Reference Notes

## Brand architecture

Master brand:
WEEMAP

Current destination / operating focus:
SINAI

Preferred visual hierarchy:

WEEMAP
SINAI

Dahab is currently the strongest operational hub, but the public brand should be capable of representing Sinai more broadly without inventing unsupported services.

## Public positioning

WEEMAP should feel like:

- a modern local Sinai travel platform
- an adventure/lifestyle brand
- a trusted local travel expert
- a real booking and operations platform

The balance should be:
functional booking platform + editorial travel brand + local soul.

## Personality

- Local
- Adventurous
- Warm
- Human
- Curious
- Confident
- Modern
- Editorial
- Premium but accessible
- Young but not childish

## Avoid

- generic Egyptian tourism aesthetics
- pyramids / airplanes / generic travel icons
- fake Bedouin clichés
- cheap excursion-shop visual language
- SaaS/dashboard styling on the public site
- generic luxury-hotel aesthetics
- fake urgency
- invented social proof
- "WEEMAP is back"
- "formerly First Trip"
- "new chapter"
- "relaunch"

## Core creative territory

Working concept:
WE MAP SINAI. YOU LIVE IT.

This is a direction, not a legal slogan requirement.

The website should communicate:
Stay + Trips + Transfers + Full Packages + Community + Partners
without expanding beyond the actual First Trip service structure.

## Visual direction

Internal design name:
Modern Sinai Editorial

Combine:
- cinematic Sinai photography
- bold editorial type
- warm sand / bone surfaces
- charcoal / near-black
- historical WEEMAP orange as a signature accent
- restrained Red Sea blue/teal where contextually useful
- real people and real places
- route / map visual language
- subtle premium motion

## Existing WEEMAP identity

Historical references show:
- orange as an important brand color
- adventure/travel storytelling
- desert, roads, sea, boats, groups and night skies
- a location-pin / hand-gesture logo concept

Do not algorithmically redesign the logo from screenshots.
Use supplied original logo/vector assets when available.
