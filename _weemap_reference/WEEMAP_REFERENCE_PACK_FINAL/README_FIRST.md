## Important rules

1. WEEMAP is an existing brand, not a "comeback" campaign.
2. Never use "WEEMAP is back", "formerly First Trip", "relaunch", or similar language publicly.
3. WEEMAP is the master brand; SINAI is the current focus.
4. Preserve the existing First Trip service structure and backend functionality.
5. Do not invent business facts, reviews, prices, destinations, history, or statistics.
6. Historical WEEMAP orange should be evolved, not discarded.
7. The supplied night-road image is a mood/composition reference, NOT necessarily a production-ready hero image.
8. The supplied website hero concept is visual direction only; do not copy incorrect/generated logo details literally.
